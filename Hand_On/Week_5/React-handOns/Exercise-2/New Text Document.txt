1) Explain React components ? 
A) A React Component is a reusable and independent piece of code that returns JSX (UI). Components help divide a user interface into smaller, manageable, and reusable parts.
	EX: 
		function Welcome(){
			return <h1> Welcome to Cognizant </h1>
		}
		export default Welcome;

2) Identify the differences between components and JavaScript functions ?
A) components: 
		Returns JSX (UI elements).
		Used to build user interfaces
		Can receive props.
		Can use React Hooks (functional components).
		Component names start with a capital letter.
		Rendered using <Component />.
   JavaScript functions: 
		Returns any JavaScript value.
		Used for general programming logic
		Receives normal function arguments.
		Cannot use React Hooks.
		Function names can follow any valid naming convention.
		Called using functionName().
